# Prüfliste Phase 1 – Test am Board

Einmal auf dem **iPhone** und einmal auf einem **Android-Gerät** durchgehen. Bitte notieren, was hakt – auch Kleinigkeiten.

## 1. Installieren

- [ ] **iPhone:** In Safari `https://wealthgatepilot.github.io/dartsapp/` öffnen → „Teilen“ → „Zum Home-Bildschirm“.
- [ ] **Android:** In Chrome öffnen → Menü ⋮ → „App installieren“.
- [ ] Die App über das neue Symbol öffnen. Sie startet ohne Adressleiste.
- [ ] Einstellungen (⚙): „Installiert: ja“. Bei „Dauerhafter Speicher“ steht im besten Fall „gewährt“.
- [ ] Hinweis: Was vorher im Browser gespielt wurde, ist in der installierten App nicht da. Das ist so gewollt (getrennter Speicher).

## 2. Offline

- [ ] Flugmodus an → App schließen und neu öffnen → Startseite erscheint, ein Spiel lässt sich starten.
- [ ] Flugmodus wieder aus.

## 3. Ein echtes Spiel

- [ ] Profile für alle Mitspieler anlegen.
- [ ] 501 Double-Out, mindestens 2 Legs, 2 oder mehr Spieler.
- [ ] Board: Zahlen sicher getroffen? Leiste gut sichtbar? Auch im Querformat?
- [ ] Mindestens einmal: Bust, Rückgängig, Dart über die Pill entfernen, „Runde bearbeiten“.
- [ ] Checkout-Vorschläge stimmen mit dem überein, was du werfen würdest?
- [ ] Bleibt der Bildschirm während des Spiels an?
- [ ] App mitten im Spiel schließen und wieder öffnen → „Spiel fortsetzen?“ → Stand stimmt.
- [ ] Spielende: Average, Darts und höchster Checkout plausibel?

## 4. Sichern und laden

- [ ] Einstellungen → „Sicherung erstellen“ → im Teilen-Menü „In Dateien sichern“ (iPhone) bzw. speichern (Android).
- [ ] Die Datei liegt in „Dateien“ bzw. im Download-Ordner.
- [ ] „Sicherung laden“ mit genau dieser Datei → „nichts zu importieren“.
- [ ] Optional: Sicherung vom iPhone auf dem Android-Gerät laden → Spiele und Profile erscheinen dort zusätzlich.

## 5. Update

- [ ] Wenn ich eine neue Version hochlade: Auf der Startseite erscheint „Eine neue Version der App ist da“ → „Jetzt neu laden“. Mitten im Spiel erscheint der Hinweis nicht.

## Rückmeldung

Für jedes Gerät: Modell, iOS- bzw. Android-Version, was gut lief, was gestört hat.
